## 🚀 本版本有什么不同？

本项目基于官方 [Clash Verge](https://github.com/clash-verge-rev/clash-verge) 进行修改，主要针对**指纹浏览器、多开浏览器以及需要为不同节点分配独立 SOCKS5 端口**的使用场景进行优化。

核心功能：

> **一个节点对应一个独立的本地 SOCKS5 端口。**

这样在使用指纹浏览器时，可以让不同浏览器配置文件分别固定使用不同的代理节点，**不需要每次手动切换节点，也不用担心切错节点。**

### 🔌 节点 SOCKS5 端口管理

新增独立的 **节点 SOCKS5 端口管理** 功能，可以直接在软件中为不同节点配置独立的本地 SOCKS5 端口。

无需手动修改 Clash 配置文件。

支持：

- ➕ 为指定节点添加独立 SOCKS5 端口
- ✏️ 直接修改节点 SOCKS5 端口
- 🗑️ 删除节点 SOCKS5 端口
- 💾 端口配置自动保存
- 🔍 自动检测端口冲突
- 🛡️ 自动检测 Clash Verge 自身保留端口
- 🏷️ 自动提示对应节点名称
- 📢 保存成功 / 失败提示

### 🌐 多端口代理

代理列表可以配置多个本地 SOCKS5 端口，每个端口对应一个节点。

![预览](./docs/捕获2.PNG)

例如：

- 节点 A → `127.0.0.1:10001`
- 节点 B → `127.0.0.1:10002`
- 节点 C → `127.0.0.1:10003`
- 节点 D → `127.0.0.1:10004`

这样不同的浏览器配置文件可以分别连接不同的本地 SOCKS5 端口。

无需反复切换 Clash 当前代理节点，直接让浏览器连接对应的本地端口即可。

### 🕵️ 指纹浏览器

本项目特别适合**指纹浏览器、多开浏览器**等需要为不同浏览器配置文件指定不同代理节点的使用场景。

![指纹浏览器](./docs/捕获3.PNG)

例如：

- 指纹浏览器 A → `127.0.0.1:10001` → 节点 A
- 指纹浏览器 B → `127.0.0.1:10002` → 节点 B
- 指纹浏览器 C → `127.0.0.1:10003` → 节点 C

每个浏览器配置文件可以固定使用对应的节点。

**不用来回切换节点，也不用担心多开浏览器时切错节点。**

### 🖥️ 节点端口显示

可以在界面中直接显示节点对应的本地 SOCKS5 端口，方便快速确认当前节点使用的端口。

![预览](./docs/捕获4.PNG)

同时支持在：

**设置 → 端口显示设置**

中调整端口显示的：

- 字体大小
- 字体颜色
- 端口显示样式

## 📌 升级说明

如果你正在使用旧版本，升级至 **1.1.0** 后即可使用新的节点 SOCKS5 端口管理功能。

### 推荐使用流程

1. 打开「节点端口管理」
2. 选择需要配置的节点
3. 输入对应的 SOCKS5 端口
4. 程序自动进行端口检测
5. 配置保存成功后即可使用

> ⚠️ 如果端口与其他节点或 Clash Verge 自身保留端口发生冲突，请更换其他可用端口。
